# 🖼️ Wallpapers Collection

A curated collection of themed wallpapers for your desktop.

## 📦 Installation

### Clone Repository (Recommended)
Clone the entire collection:
```bash
git clone https://github.com/jalexsan/wallpapers.git
```

> **Note:** You need Git installed on your system to clone this repository.

**Check if Git is installed:**
```bash
git --version
```
**📝 Setup Git on your system:**

<details>
<summary><strong>Click to see installation instructions</strong></summary>

### Windows
**Using winget:**
```bash
winget install Git.Git
```

**Using installer:**
1. Download from [git-scm.com](https://git-scm.com/download/win)
2. Run the installer
3. Follow the setup wizard (default options work fine)
4. Restart your terminal

### macOS
**Using Homebrew:**
```bash
brew install git
```

**Using Xcode Command Line Tools:**
```bash
xcode-select --install
```

### Linux

**Ubuntu/Debian:**
```bash
sudo apt update
sudo apt install git
```

**Fedora:**
```bash
sudo dnf install git
```

**Arch Linux:**
```bash
sudo pacman -S git
```

**openSUSE:**
```bash
sudo zypper install git
```

### Verify Installation
After installation, verify Git is working:
```bash
git --version
```

</details>

### Download Individual Themes
Visit the [Releases page](https://github.com/jalexsan/wallpapers/releases/latest) to download specific theme zips:
- `Catppuccin_Mocha.zip`
- `Gruvbox_Retro.zip`
- `Nordic_Blue.zip`
- ... and more!

Each theme is available as a separate download so you can get exactly what you want.

# 🐍 Rename Wallpapers Script

> [!NOTE]  
> You can use the [rename_wallpapers.py](https://github.com/jalexsan/wallpapers/blob/master/rename_wallpapers.py) script to keep your wallpapers organized.  
> It renames them to a format like **01.Theme_Name.jpg**, **02.Theme_Name.jpg**, and so on.  
>  
> If you want to use the Python tool, you can download it separately from the [Releases](https://github.com/jalexsan/wallpapers/releases/latest) and place it in your `wallpapers` folder.  
>
> To use the script, open a terminal in the `wallpapers` folder, then run:  
> ```bash
> python3 rename_wallpapers.py
> ```  
>  
> **Feel free to fork the repo and customize it for your own collection!**
